# Contributing

Спасибо за интерес к проекту! Баг-репорты, предложения новых фич и улучшения в код принимаются!

# Быстрый старт

1. Сделайте форк репозитория, склонируйте его и настройте окружение в соответствии с README
2. Сделайте feature branch и пишите код туда, ветку отводите от dev
3. Реализуйте вашу фичу, если у вас есть несколько фич, то лучше разбить их на отдельные PR
4. Создайте PR в ветку dev основного репозитория

# Если есть вопросы

Если у вас есть вопросы, то напишите мне на почту (YagodnikDev@yandex.ru) или откройте issue
